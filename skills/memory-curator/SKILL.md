# Memory Curator
Inputs: durable fact or search query, scope, source, tags.
Outputs: journal memory event or ranked excerpt set.
Keep full session records on disk and rebuild search from journal plus session files.
Never store credentials, duplicate gate truth, replay full sessions, or preserve stale claims after contradictory evidence.
Behavior: curated memory cites its source and search results remain bounded.
