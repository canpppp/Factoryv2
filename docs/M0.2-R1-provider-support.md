# M0.2 subscription-provider boundary decision

Decision, not certification. Real profiles remain `ISOLATION_UNSUPPORTED`
before spawn. No credentials, inference, egress enabling, infrastructure or host
sandbox experiment were used. This updates R1 with accepted R1/R2 and M0.2-C
integration and the Linux ownership proof, preserving earlier limitations.

## Recommended Next Boundary

Choose a **Linux-isolated, read-only Claude Code 2.1.259 reviewer**, owned by the
existing Factory daemon independently of its UI/client. Defer the previous
host-native proposal while the six-process macOS incident is open. Disposable
Ubuntu 22.04 / bubblewrap 0.6.1 CI is evidence, NOT a production service.

This proposed mount layout requires later architectural/operator authorization.
It is not an enabled configuration. Business input must be an immutable
exact-revision snapshot: read-only binds do not freeze concurrent host writes.
