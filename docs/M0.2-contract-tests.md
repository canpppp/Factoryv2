# M0.2 contract-to-test plan

Baseline: `82f2e48d1ca450f92de98898d570f145d70d5b0c`.
Scope: worker isolation/lifecycle; deterministic fixtures only. No live inference.

| Contract | Allowed | Denied | Failure/race evidence |
| --- | --- | --- | --- |
| Immutable policy | Channel defaults, job subsets, stable profile digest on resume | Extra tools/roots, larger budgets, executable/env/auth overrides | Policy change invalidates session; absent enforcement blocks before spawn |
| Environment/config | Named runtime variables, dedicated state root, explicit subscription auth | Ambient API keys, PATH/NODE_OPTIONS, plugins/MCP/settings | Sentinel ambient config and environment through channel-adapter-process |
| Filesystem/tools | Fixture reads approved file; Claude explicit available tools | Outside read/write, symlink escape, unapproved tool | OS sandbox test; unsupported provider/platform returns ISOLATION_UNSUPPORTED |
| Output | Valid bounded JSONL | Oversized unterminated line, total stdout, event/invalid/stderr flood | OUTPUT_LIMIT; bounded retained bytes/count; no successful clipped receipt |
| Lifecycle | Owned run ID before session ID, normal result | Late callbacks, unowned process signals | Repeated cancel, pre-ID cancel, timeout race, spawn error, TERM-ignoring child/grandchild |
| Receipts | Provider/executable/profile/source identity, cause and counters | Credential text or synthetic live proof | Failure attempt journal, no completion promotion, prior M0.1 guards |

Production-path tests exercise registry -> adapter -> child process. Existing
protocol tests remain synthetic. Unsupported enforcement is a blocker, not
permission to fall back to ambient execution. Final checks: focused tests,
one full npm test run after relevant fixes, remote CI proof at final revision.
