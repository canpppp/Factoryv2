# M0.2 OWNER contract

Base: 60bacb452481e42343ee166f4061f5f4973aa729. Engineering only; no live provider proof.

| Contract | Allowed | Denied / failure and race proof |
| --- | --- | --- |
| Owner | Canonical root, exclusive generation, private endpoint, readiness after reconciliation | Second owner; unknown lock/socket; wrong root; stale generation cleanup |
| Admission | Explicit mission + durable request key + bounded steps | Changed payload, client policy/config, concurrent requests for one mission |
| Reconnect | Exact persisted request/attempt/result after client loss | Latest-result substitution; treating admission as objective completion |
| Startup | Unstarted admission survives restart | Started/uncertain attempt replay; interruption before readiness, before identity, before release |
| Consumers | Actual Linux CLI -> daemon -> isolated synthetic process | No provider inference; no integration/candidate/release fixture transitions |
| Cleanup | Current PID/start/namespace evidence, finite lifetime, independent watchdog | Any watchdog intervention or active remainder fails |

Production run attaches only. Direct controller and daemon.runOnce remain local library
test APIs without durability claims. CLI local test execution requires --local-test,
is never fallback, and refuses roots containing an owner record.

## Proof mapping

- owner-parser.test.js: payload/idempotency, exact stored results, uncertain
  request replay, channel cleanup-receipt interruption, partial journal refusal.
- owner-consumers-proof.test.js (Linux only): actual CLI client loss/reconnect,
  simultaneous and duplicate daemon starts, missing/not-ready/wrong-root owner,
  unknown/non-socket refusal, stale recorded socket recovery and old-generation
  close refusal. Five scenarios run both focused and in npm test.
- The same Linux consumer proof interrupts before readiness, after fsynced
  admission, before namespace identity and after identity/before permit.
  It asserts no pre-permit worker invocation, one known-safe invocation after
  unstarted recovery, uncertain replay refusal and watchdog cleanup inventories.
- Prior controller-policy, R1/R2, namespace ownership and the complete Factory
  suite remain required, not replaced by new helper tests.
